# Sensor Collection project for fun!

## Installing the project from pypi

The project is uploaded to the test pypi only so the command to install is as follow:

python3 -m pip install -i https://test.pypi.org/simple/ yogomatt-sensor --upgrade

Check the upload by browsing https://test.pypi.org/project/yogomatt-sensor/

## Running the project from command line

Once installed, console scripts (see file setup.py) are added to the Operative System environment. Therefore the execution is as simple as executing:

>
> nohup yogomatt-dht22 &
>
